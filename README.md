> 一个基于 Unity 引擎开发的 3D 坦克对战小游戏。这是我的第一个完整 Unity 项目。

- **游戏类型**：3D 射击 / 对战
- **开发引擎**：Unity [2022.3.62f3c1 LTS]
- **开发语言**：C#

## 🕹️ 操作说明
- `W / A / S / D` ：控制坦克移动
- `左键`：发射炮弹
- '右键'：连续发射炮弹
- `ESC`：退出游戏

## 📥 如何运行源码（暂时无打包版本）
本项目目前仅上传了源码，未提供打包好的 `.exe`。如果你想在本地运行：
1. 下载本仓库代码（点击 `Code` -> `Download ZIP`）。
2. 解压后，使用 Unity Hub 打开该项目（确保本地安装了对应的 Unity 版本）。
3. 在 `Assets/Scenes` 文件夹中找到主场景，双击打开。
4. 点击 Unity 编辑器上方的播放按钮即可运行。

## 🛠️ 技术要点 / 我的收获
- **物理系统**：使用 `Rigidbody` 和 `Collider` 实现坦克碰撞与炮弹物理飞行。
- **脚本通信**：通过 `GetComponent` 和事件系统处理坦克与炮弹之间的伤害逻辑。
- **游戏管理**：使用单例模式（Singleton）管理游戏状态（开始、进行中、结束）。
